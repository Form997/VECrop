# Variables and Units

| Symbol | Meaning | Typical unit |
|---|---|---|
| \(\Psi\) | Water potential | MPa |
| \(J_w\) | Water flux | model-dependent flux unit |
| \(K_h\) | Hydraulic conductivity/conductance | must match flux formulation |
| \(C_i\) | Ion concentration | mol m⁻³ or mmol L⁻¹ |
| \(a_i\) | Ion activity | activity convention |
| \(V_m\) | Membrane potential | V or mV |
| \(A_n\) | Net photosynthesis | µmol CO₂ m⁻² s⁻¹ |
| \(E\) | Transpiration | mol H₂O m⁻² s⁻¹ or equivalent |
| \(LAI\) | Leaf area index | dimensionless |
| \(M_i\) | Element mass/content | mass or mol per plant/area |
| \(HSY_{diag}\) | Diagnostic integrated state index | dimensionless [0,1] |
